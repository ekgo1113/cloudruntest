2024. 03. 28
이번 세미나는 혁신적인 기술과 AI의 역할에 초점을 맞추어 디지털 세계의 미래를 제시하는 것을 목표로 3가지 세션으로 진행되었습니다.

1. Apigee Gen AI를 위한 API 관리 솔루션 - 홍창배(Google Cloud Apigee Specialist CE)
2. 대한항공 전사 API관리 Apigee 구축사례 - 구제서 팀장(대한항공 클라우드 기술팀)
3. AI와 데이터 분석의 파워로 이끄는 비즈니스 혁신 - 이규현 프로(이원정보기술 BC본부)

마지막에 진행한 Dynatrace를 통한 AI와 데이터 분석 파워로 얻을 수 있는 GCP 성능 최적화 발표는 세미나의 성과를 최대화하고, 참석자분들의 많은 관심과 호응을 얻는 세미나였습니다.
